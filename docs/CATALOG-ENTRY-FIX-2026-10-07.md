# 首页进入知识地图和标签页的空白问题

日期：2026-10-07。状态：本地修复，未发布。

用户报告：从首页点击知识地图或标签栏目后，只显示标题、导航和页脚；刷新后可看到完整内容。

## 排查证据

线上首页的隐藏目录容器为空。点击栏目后，旧路径执行客户端切页，再按需下载 `catalog-renderer` 模块及目录 JSON。检查中复现了切页后至少 3 秒内容仍为空，较长等待后内容成功显示；本轮没有观察到稳定的 HTTP 错误，不能据此认定 CDN 一直不可用。

直接打开或刷新栏目则得到构建时预生成的完整 HTML，不需要等上述模块和 JSON 才能显示。两条入口路径的差异解释了用户观察到的现象。

## 修复

`lib/router.mjs`：从首页进入 `/roadmap/` 或 `/tags/` 时，使用浏览器正常页面导航，直接展示已有预生成内容；当前渲染器尚未建立或加载失败时，进入这两类路由也使用同一方式。正常情况下目录内部继续使用现有客户端导航。

没有增加额外轮询，也没有混用 CDN 与源站的模块实例。首页继续按需加载目录增强功能，不提前下载完整目录数据。普通页面导航保留原有 URL、登录 Cookie 和会话存储。

## 回归验证

新增 `e2e/catalog-entry.spec.mjs`：

- 故意阻断目录增强模块及知识地图、标签索引 JSON。
- 从首页分别点击两个栏目，确认浏览器实际请求相应文档，内容可见。
- 增强模块无法加载后继续切换另一栏目，确认仍显示其预生成内容。

原首页懒加载测试保留，并在确认目录渲染器就绪后检查模块请求，避免把预生成内容提前可见误判为脚本已完成初始化。

最终验证：`npm run verify:parallel` 全部通过（658 项单元测试、语法和 Lint、训练索引、构建）；完整 `npx playwright test` 61/61 通过，其中包含 2 项新增的目录入口故障模拟测试。
