# 训练状态与提交表单专项规格

日期：2026-09-16。对应 [产品设计](LEARNING-STATE-DESIGN.md)。本专项替代旧文档中将 `reviewStatus` 同时解释为错题、掌握和复习状态的部分。

## 1. 数据契约

日志写入版本当时为 `schemaVersion: 5`，保留 v4 的附件、来源与 AI 分析字段（2026-09-18 追加题面图片后，当前写入版本为 `schemaVersion: 6`，本专项的状态字段语义不变）。

| 字段 | 合法值 | 默认 / 兼容 |
| --- | --- | --- |
| `outcome` | `independent`, `hinted`, `editorial`, `unfinished` | 未填写保持缺失；计分按 unknown |
| `masteryStatus` | `unknown`, `learning`, `mastered` | `unknown` |
| `isMistake` | 布尔值 | `false`，表示未标记，不是机器认定全程无错 |
| `reviewStatus` | `none`, `todo`, `archived` | `none` |
| `reviewDue` | 既有日期格式 | 仅待复习安排使用 |

共享读取入口为 `lib/learning-state.mjs`。旧 `reviewStatus=mastered` 读取为 `reviewStatus=none`，在没有显式掌握自评时映射 `masteryStatus=mastered`；显式自评优先。不从旧 todo 推导 `isMistake=true`。

## 2. 必须保持的不变量

- 改变任一状态不隐式覆盖其他三个状态。
- 任意 outcome 与任意 masteryStatus 均可安排复习，包括独立完成且已掌握。
- 错题是人工标记的这次训练信息，与安排复习相互独立。
- 结束复习只设置 archived 并清理到期日期，不生成已掌握或成功重做证据。
- 活力计算不得读取 masteryStatus、isMistake、reviewStatus 来折算完成质量；现有 outcome 权重不变。
- AI 元数据回填不改写上述四个状态。
- 普通保存与带 PDF/题面图片的保存都保留新字段，条件版本校验与附件事务保持原契约。

## 3. 读取与展示范围

表单服务端加载、账号隔离草稿、编辑回填、保存校验、元数据文件、个人训练索引、静态生成、卡片、详情、导出和课程统计均使用一致的状态语义。

复习页包含 todo 与 archived；首页到期队列只包含到期 todo。未安排复习与未标记错题不得互换文案。旧「已掌握」筛选的复习含义改为「已归档」，掌握自评另行展示。

## 4. 界面要求

- 每个输入有明确标签，完成结果与掌握自评各自独立。
- 题面/PDF/AI 常驻展示；代码按需展开，展开不丢失已填值或待上传附件。
- 待复习时显示日期；切换掌握或错题标记不改变日期或安排。
- 折叠控件、输入与保存可用键盘操作；状态反馈可被辅助技术读出。
- 桌面与手机均无表单横向溢出，主保存入口不被内容遮挡。

## 5. 验收矩阵

| 场景 | 验收结果 |
| --- | --- |
| 独立完成 + 已掌握 + 待复习 + 未标错 | 保存、回填四项一致，进入复习队列，活力不变 |
| 独立完成 + 错题标记 | 保留独立完成，不自动变未完成或待复习 |
| 未完成 + 已掌握 | 允许独立自评，完成结果仍未完成，保留 0.15 权重 |
| todo → archived | 只结束安排，完成结果、自评、错题标记不变 |
| 每个 outcome 下遍历其余三项组合 | 对同一训练历史活力结果一致 |
| 旧 mastered | 自评已掌握 + 未安排复习，无虚构复习事件 |
| 旧 todo 无 outcome | 继续待复习，结果仍缺失、错题未标记 |
| v5 普通与附件保存后读取 | 四项与附件引用完整保留 |
| 草稿恢复与编辑 | 不把旧掌握值写回复习状态，不丢新字段 |
| 桌面 / 手机 | 字段与工具层级清楚，折叠区域可操作 |

测试与浏览器核查结果以 [交接文档](HANDOFF.md) 最新一节为准；本规格本身不构成部署证明。
