# 训练日志提交独立页面：施工规格

初稿日期：2026-09-21。最近更新：2026-09-25。状态：已实施并进入维护；本文保留为布局与行为契约。

当前实现使用 `/submit/` 独立页面、左侧题目目录、中央编辑区、右侧提示区和吸底保存栏。2026-09-25 修复了复习设置中日期字段被旧样式强制定位到第 3 列而换行的问题：1440/1024px 下四项同排，800px 下双列排列且“错题标记 / 复习日期”同排，390px 下单列。浏览器冒烟由 `npm run smoke:submission` 覆盖这四个宽度。

## 1. 目标与范围

参考用户提供的设计图，将现有提交弹窗升级为可直接访问、刷新和前进后退的独立页面。沿用现有业务与数据结构，只调整提交入口、表单承载方式及页面内布局。

参考图是视觉与排版参考，其中的日期、用户名、题目、统计数字、计划和字数上限均不是业务要求。用户“不要动其他东西”的约束优先于历史产品文档中的扩展计划。

不改变首页、统计、复习、知识地图、标签、成员和题目详情页面的布局，不重做全站导航、登录、搜索或主题；不增加计划系统、统计接口、编辑器框架、后端接口或数据迁移。

## 2. 已核实的现状

| 位置 | 现状及迁移影响 |
| --- | --- |
| `src/index.html` | `#submission-page` 承载独立提交视图、三栏工作区、工具栏和保存栏 |
| `src/app.js` | 提交按钮按需加载 `lib/form.mjs`，并绑定导入、日期切换及保存事件 |
| `lib/router.mjs` | 使用路径和 History API 切换 `.page-view`，识别 `/submit/` 及查询参数 |
| `lib/form.mjs` | 包含日期加载、账号隔离草稿、导入、题面及附件、AI 辅助、提交、删除与题目定位 |
| `lib/renderer.mjs` | 历史记录通过 `openModalForDate(date, problemId/index)` 定位编辑 |
| `scripts/generate-data.js` | 负责静态站构建、入口资源版本及 Service Worker；新路径需验证直接访问 |
| `src/style.css`、`src/assets/ink-mountains.webp` | 已有绿色界面、提交区域样式与山水素材，可复用 |

当前完成结果已有 `independent`、`hinted`、`editorial`、`unfinished` 及未记录空值；无需增加字段。实际每次最多 15 题，心得上限 100,000 字符，统一读取 `LOG_LIMITS`，不照搬图中的 10 题和 5,000 字符。

## 3. 页面与路由

- 路径为 `/submit/`；指定日期使用 `/submit/?date=YYYY-MM-DD`，定位题目可附带 `problem=<稳定记录ID>`。旧记录缺少 ID 时，内部调用仍兼容原索引。
- 使用现有应用壳增加独立 `.page-view`，拥有页面标题和正常文档滚动，不保留弹窗遮罩、焦点锁定或 `aria-modal`。这里的独立页面指独立 URL 和页面视图，无需建立第二套应用。
- 首页及顶部现有提交入口只改变跳转行为；历史编辑入口携带日期与题目定位。顶栏不新增菜单项，不改变原导航项文案和排列。
- 新记录标题“提交训练日志”，编辑已存在日期时为“编辑训练日志”；面包屑为“训练记录 / 新建日志”或“训练记录 / 编辑日志”。提供返回训练记录入口。
- 未登录直接访问显示登录引导，不初始化别人的草稿。登录后恢复目标日期；实施时检查现有登录回跳机制，仅做该入口必要适配。
- 日期遵守现有 UTC+8 规则及未来日期限制；非法日期明确提示，不静默加载另一日。日期切换同步 URL，查询参数变化也必须触发加载，不能只比较 pathname。
- 构建需保证 `/submit/` 直接访问、刷新及分享有效，资源路径不因嵌套路径失效；沿用现有静态路径输出机制，不假设托管环境一定有 SPA 回退。

## 4. 视觉与内容布局

设计方向：参考图的淡绿山水背景、深绿强调色、白色卡片和清晰主次。仅在新页面作用域内应用；正文使用现有字体，标题可沿用既有衬线风格。复用山水素材，不引入整站背景变更。

### 桌面端（宽度 ≥ 1280px）

采用三栏：左侧约 220px、中央弹性且至少约 600px、右侧约 240px，间距约 24px。页面可用宽度不足时优先减少辅助栏，不压缩输入区。

1. 左侧“本次记录”：所选日期、已添加题数、题目目录、添加下一题、本地草稿状态。目录显示序号、题名和平台题号；点击滚动到对应题卡，删除后顺序同步。进度如显示容量，明确为“已添加 n / 15 题”，不是完成率。
2. 中央顶部：面包屑、标题、一句说明；日期、CF 导入、洛谷导入、AtCoder 导入和手动添加工具栏。连续训练开始/结束日期放入可展开的“训练区间”，保持原值和校验。
3. 中央主体：多题卡片纵向排列；主编辑内容在正常页面滚动中呈现，避免多层滚动容器。
4. 底部：编辑区域内吸底操作栏，显示题数、保存反馈、“保存草稿”和“保存训练记录”；已有记录使用“更新记录”。整日删除保留为明确的次级危险操作，与单题移除区别显示。
5. 右侧：保留参考图的轻量辅助卡片节奏，使用“记录提示”和可选装饰引言。首版不制作可勾选的“今日计划”，不新增训练统计查询，也不显示示例数字；避免将页面迁移扩展为新功能。装饰山水不压在表单文字下。

### 题目卡片

- 卡头：序号、题名、平台/题号、移除按钮。手动新建时直接展示题名与题号输入，不能把必填字段藏到折叠区域而无提示。
- 默认展开：完成情况与收获/题解。完成情况用原生单选控件呈现四个选项，另保留“未记录/清除选择”；导入或旧日志不自动认定独立完成。
- “题目信息”：平台、题号、题名、难度、标签；卡头内容与表单使用同一份状态，不重复维护两个可编辑副本。
- “代码（选填）”：迁移现有代码输入能力，不因参考图文案新增多语言多代码块模型。
- “复习设置”：完整保留掌握自评、复习安排、错题标记与复习日期；不默认填入图示的七天复习。
- “题面与附件”：保留题目描述、题面获取、AtCoder 页面解析、AI 概括、DeepSeek 辅助及现有归档能力，能力和限制不变。
- 折叠区摘要展示真实字段；保存校验发现错误时自动展开相关区域并聚焦首个错误。
- 列表底部的“添加下一题”和工具栏、左侧按钮复用同一添加操作；达到现有上限时禁用并说明原因。

### 响应式与可访问性

- 900–1279px：右侧辅助栏隐藏，保留目录和主编辑区。
- 小于 900px：单栏；题目目录改为可展开区，工具栏换行，完成选项按空间排列。保存栏预留底部导航与安全区，不遮挡最后一个输入框。
- 自动化验收宽度为 390px、800px、1024px、1440px，并兼顾 200% 缩放、亮暗主题及键盘操作。输入控件保持可读尺寸，无页面横向溢出。
- 折叠使用可访问的原生结构，单选组具备名称；异步结果使用状态播报。路由进入聚焦页标题，定位编辑聚焦目标题卡，不再把键盘焦点锁在表单内。

## 5. 行为与可靠性契约

1. 沿用现有日期读取、字段收集、校验、导入、请求和错误处理，不因布局迁移重写数据协议。保存仍按当前日期的现有语义执行，不能把整日更新改成仅提交当前可见题。
2. 草稿继续按账号和日期隔离。“保存草稿”调用既有草稿存储能力，不发正式保存请求；只有存储成功才显示“已保存到此浏览器”及时间，失败明确提示。自动草稿和手动草稿统一状态来源。
3. 切换日期、离开页面、前进后退及刷新时保护未保存输入；草稿确实落盘且无不可恢复内容时无需反复确认，存在尚未归档的附件或存储失败时提示。不得宣称附件二进制已被普通本地草稿完整保存。
4. 保留现有异步日期请求顺序控制；切号、退出、离开页面后的旧响应不得覆盖新状态。移除弹窗专用历史栈补写逻辑，避免返回循环。
5. 保存中避免重复提交；成功沿用当前版本/幂等及草稿清理保护逻辑（以实际现有实现为准），留在页面显示结果与查看记录入口。提交失败保留所有输入；不把“已写入”误报为“公开页面已发布”。
6. 读取失败时显示重试入口，禁止以空表单覆盖已有日期；导入失败不清空已填内容。导入选择、去重与字段填充沿用现有行为。
7. 空表单、移除最后一题、长标题、大段心得、历史缺字段及题目定位失效均有可用状态；失效定位回到当日列表并提示，不加载其他日期代替。

## 7. 验收清单

- 原提交入口进入 `/submit/`，没有旧弹窗；直接刷新、带日期访问、前进后退和历史题目定位均正确。
- 未登录引导、账号切换和日期切换不串草稿；慢请求不串日期；本地存储失败有反馈；未归档附件离开时有保护。
- 手动添加、三平台导入、四种完成结果及未记录、心得、题目元数据、代码、复习、题面/AI/附件、整日删除全部可用。
- 用固定样本比较迁移前后收集的业务字段，确保折叠或导航未丢字段；保存失败及重试不丢输入、不重复创建记录。
- 成功反馈与发布状态真实，保存草稿不会正式提交；现有限额与校验保持一致。
- 对 390/800/1024/1440px 和亮暗主题进行一轮截图检查，修正实际问题后复查；目录与保存栏不挡内容，键盘可完成录入。
- 复用 `test/form-drafts.test.mjs`、`test/draft-store.test.mjs`、Schema 测试，并由 `scripts/smoke-submission-page.mjs` 覆盖独立页布局和溢出回归；交付前执行项目验证流程。
- 对首页、统计、复习、知识地图、标签、成员与题目详情抽查外观和入口，除指定编辑跳转外行为不变；最终差异审查不得出现无关修改。

完成标准：参考图的主要构图已落地为独立提交页面，原有记录能力完整保留，其他页面和数据协议不变。本文件作为后续维护与回归依据。
