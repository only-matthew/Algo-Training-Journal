# 活力 v2.1：重做中的学习收获

保留 v2 的难度、匹配度与完成质量折算。同题基础额度仍按最佳完成结果补差额；不同题数仍按成员与题目身份去重。

重做或显式 review/practice 记录的非空心得，与该成员此前同题心得不同，可获得额外复盘活力。心得先通过历史占位过滤、NFKC 规范化、空白去除，再比较全文；首次普通训练的心得不额外加分，重复全文不加分。缺难度的记录不消耗额度。

第 n 次额外复盘额度为 B × outcomeCredit × 0.25 × 0.5^(n−1)，B 优先沿用同题首次有效基础单位。完成质量补差额与复盘额度可同时发生。普通同题额外额度累计不超过 0.5B；显式复习没有基础记录时按当次匹配度估算。相应能力证据也获得同权重增量，并从次日生效。

新增状态 reflection_gain 表示计入复盘活力。成员、平台、日曲线与热力图沿用统一聚合路径。文本差异只是训练证据的保守代理，不评价质量，也不能证明产生了新领悟；未识别到额外心得或零额外活力都不等于没有学习。修改、删除或版本升级会重算历史。
